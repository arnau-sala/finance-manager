## Capture Notes

- Use demo or anonymized data only
- Prefer PNG for full mobile screenshots
- Prefer PNG for full mobile screenshots
- Keep account emails on reserved domains such as `example.com`
- Avoid showing real recovery codes, private emails, or personal transactions
